# Brain Darts (repo: brain-atlas)

GeoGuessr-style neuroanatomy game: show a brain slice, name a region, the player
clicks ("throws a dart"), points depend on distance. Two species: **mouse** (Allen
CCFv3) and **human** (Allen Human Reference Atlas), chosen on a species picker.
Also review (spaced repetition) and study modes. Meant for
studying for neuroanatomy exams. Owner is a biology student (comfortable with
Python/R, new to web dev): keep tools simple, explain technical choices briefly,
and keep code readable and commented.

## Working agreements
- Plan first, wait for OK, then build milestone by milestone. Commit at each milestone.
- **Never guess API endpoints, IDs, or file formats.** Verify with a real request or
  the docs and show the evidence. If something behaves unexpectedly, say so; don't
  silently work around it.
- After each milestone: give exact run commands and what to click to test.
- Scoring and pixel → region lookup are what decide correctness; keep them pure
  functions with unit tests.
- Genre inspiration is fine, but do not copy GeoGuessr's name, logo or assets.

## Layout
```
pipeline/              Python: download Allen data, export slices (run once)
  build_atlas.py       MOUSE: downloads → checks → exports both resolutions
  build_human.py       HUMAN: downloads plates + SVG outlines → label maps → export
  atlas_lib.py         pure helpers (ontology flattening, label remap, region stats)
  human_lib.py         SVG outlines → label maps (scanline even-odd fill)
  stream_nrrd.py       reads chosen coronal slices from huge gzip NRRDs without loading them
  net.py               safe cached download (certifi)
  tests/               pytest
  cache/               downloaded raw files (gitignored: mouse ~410 MB + 2.2 GB unused Nissl;
                       cache/human/ 104 MB)
web/                   Vite + TypeScript static site, no framework, no backend
  public/data/mouse/   GENERATED by build_atlas.py, committed (8.6 MB)
  public/data/human/   GENERATED by build_human.py, committed (42 MB)
  src/types.ts         JSON shapes shared with the pipeline
  src/tree.ts          region-tree helpers (isWithin, descendantMask, regionAtLevel, breadcrumb)
  src/labelmap.ts      .bin.gz decoding, pixel lookup, click→slice coords, nearest target, pixel counts
  src/scoring.ts       distance → points, parent partial credit
  src/game.ts          choosing rounds (weighted, review rounds), rank titles
  src/review.ts        spaced repetition: Leitner boxes, due regions, saved-progress parsing
  src/data.ts          fetching data files (lazy, cached per slice + quality)
  src/render.ts        canvas drawing (stage, overlay layers, pin, line)
  src/ui.ts            DOM helpers (animations, count-up, confetti)
  src/storage.ts       best scores, quality setting and review progress in localStorage
  src/play.ts          game screen    src/study.ts   study mode
  src/main.ts          entry: species picker (#mouse / #human), menu, screen switching
  src/style.css        the whole look (colour variables at the top)
```

## Rebuild the data
```
cd pipeline
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python build_atlas.py     # mouse: first run downloads ~410 MB into cache/; ~20 s, ~2.7 GB RAM peak
python build_human.py     # human: first run downloads 104 MB (4.5 min); export ~3 min
pytest
```
Then commit `web/public/data/`. Mouse rebuilds are byte-for-byte deterministic.

## Data sources (verified 2026-11-22)
- Ontology: `https://api.brain-map.org/api/v2/structure_graph_download/1.json`.
  Nested tree with `id, acronym, name, color_hex_triplet, parent_structure_id, children`;
  1327 structures; `success: true` at top level, tree under `msg[0]`.
- CCF volumes under `https://download.alleninstitute.org/informatics-archive/current-release/mouse_ccf/`:
  - `annotation/ccf_2017/annotation_{25,10}.nrrd` (uint32, gzip; 25 µm 528×320×456 = 4 MB,
    10 µm 1320×800×1140 = 33 MB download / 4.8 GB unzipped)
  - `average_template/average_template_{25,10}.nrrd` (uint16; 33 MB / 343 MB download).
    Two-photon autofluorescence average of ~1,700 brains, **not** Nissl; smooth by nature,
    so 10 µm is only slightly sharper than 25 µm.
  - `ara_nissl/ara_nissl_{10,25,50,100}.nrrd` (float32; 10 µm = 2.2 GB). Checked
    2026-11-22: real cell layers (CA, DG) but grainy, weaker thalamus/tract contrast,
    some artifacts; ~15–20 MB extra as PNGs. **Not used** (owner to decide).
- Structure sets (difficulty levels): listed via
  `https://api.brain-map.org/api/v2/data/query.json?criteria=model::StructureSet&num_rows=all`
  (50 sets). Members via
  `...?criteria=model::Structure,rma::criteria,structure_sets[id$eq<SET>]&num_rows=all`.
  Used: **3 "Mouse - Areas"** (51) for medium, **167587189 "Brain – Summary Structures"**
  (316, "non-overlapping substructures at a mid-ontology level") for hard.
  687527670 "Brain - Major Divisions" (12) = our easy list minus fiber tracts and VS.
- **Human** (verified 2026-11-22): Allen API atlas **138322605** "Human, 34 years, Cortex -
  Gyral" (265297126 "Mod. Brodmann" = same images); Ding S.-L. et al. 2016, J Comp Neurol
  524(16):3127–3481, doi:10.1002/cne.24080. **106 annotated** of 641 images, section
  thickness 50 µm (AtlasDataSet 100149965), plates 0.8 mm apart (median; max 4.35 mm).
  - list: `query.json?criteria=model::AtlasImage,rma::criteria,[annotated$eqtrue],atlas_data_set(atlases[id$eq138322605])`
  - image: `image_download/<id>?downsample=6` (302 redirect → JPEG, ~1144×1558 for a middle
    plate; "sharp") and `downsample=7` ("light"). Plate sizes and µm/px (0.968–1.09) differ per plate.
  - outlines: `svg_download/<id>?groups=…`. SVG canvas = full-res pixels; path coords ×
    group `transform` = full-res pixels; image px = full-res / 2^downsample (checked: canvas
    73248×99744 = 64 × 1144.5×1558.5).
  - ontology: `structure_graph_download/16.json` (3317 structures, depth 14).
  - `brainglobe-atlasapi` `allen_human_500um` exists but is far coarser; not used.

## Known quirks (verified on the real data)
- **NRRD header lies about orientation.** It says `space: left-posterior-superior`,
  but arrays are stored as (AP, DV, LR): axis0 anterior→posterior, axis1
  dorsal→ventral, axis2 left→right. `build_atlas.py:check_orientation` checks this
  on the anatomy (MOB before CB, Isocortex above HY, 96.4 % L/R mirror symmetry)
  and exits if it ever fails. Known issue: Allen community forum, BICCN
  cell-locator issue #48.
- NRRD data is stored first-axis-fastest, so one coronal slice is spread over the
  whole file; `stream_nrrd.py` unzips once and keeps the needed AP columns.
- 10 µm and 25 µm labels agree on 96–98 % of brain pixels per slice (edges differ by
  downsampling); the build exits if any slice is below 80 % or a target is missing at 10 µm.
- **Structure ids go up to 614454277** (128 ids > 2^24), so raw ids can't be packed
  into RGB PNGs. We map ids to a compact `index` (position in structures.json, fits
  uint16) and store label maps as gzip-compressed raw uint16 (`.bin.gz`).
- **Tree depth ≠ region size** (CB depth 2, TH/HY 4, Isocortex/HPF 5, CA1 8), so
  difficulty uses curated sets, not raw depth.
- The python.org macOS Python has no root certificates by default
  (`CERTIFICATE_VERIFY_FAILED`); downloads use `certifi`. Never disable verification.
- `apMm` is distance from the front of the CCF volume, **not** bregma.
- Several Allen colours are grey (VS `#AAAAAA`, fiber tracts `#CCCCCC`) and vanish on
  the grey slice, so the answer/selection is shown in a fixed cyan (`render.ts:HIGHLIGHT`).
- Browsers report clicks in whole CSS pixels (Chrome: `clientX` truncated). At the
  default size that is ≈0.5 slice px at 25 µm. Expected, not a bug.
- The slice frame has rounded corners with `overflow: hidden`; clicks in the clipped
  corners don't reach the canvas (nothing is drawn there either).
- Some acronyms equal the name ("fiber tracts"); the prompt hides the acronym then.
- **Human SVG groups**: "Atlas - Developing Human …" groups have graph-16 ids: main (31,
  deep structures incl. hippocampal layers), Gyri (113753815), Brodmann (265297118),
  Sulci (113753816), Hotspots (141667008). "Atlas - Human …" groups use ids NOT in graph
  16 (other ontology) → ignored. Label maps: `gyral` = Gyri then main on top, `brodmann` =
  Brodmann then main on top (the gyrus outline "hippocampal gyrus" covers CA1/DG/subiculum;
  2.3 % of gyri pixels overlap, almost all hippocampal).
- **Human sulci are only tiny arrowhead markers**, not areas → not drawn, never asked.
  **Corpus callosum / internal capsule are not outlined** (white matter is one region;
  tracts only have small hotspot markers) → not asked. Fornix and optic tract are outlined.
- **Graph 16 has parallel trees** (surface structures: lobes > gyri; grey matter: nuclei,
  Brodmann areas). Cerebellar lobules (CbSS) are not under "cerebellum" (CB), so
  `build_human.py:attach_cerebellar_surface` moves CbSS under CB — the one deliberate
  change to an Allen tree.
- Human tissue coverage by outlines ≈ 96 %; uncovered = slide edges/specks. Pale Nissl white
  matter is labelled (FWM), never asked.
- Pillow's polygon fill colours edge pixels on both sides (holes 1 px too big), so
  `human_lib.fill_mask` is a numpy scanline fill (pixel centre inside, even-odd).
- Vite's dev and preview servers send `.gz` files with `Content-Encoding: gzip`, so the
  browser unzips them before our code sees them. Other hosts may not.
  `labelmap.ts:gunzipIfNeeded` checks the gzip magic bytes (1f 8b) and handles both.

## Data format (web/public/data/<species>/)
- `structures.json`: array; entry i has `index == i`. Entry 0 = "outside brain"
  (annotation value 0). Fields: `index, id, acronym, name, parentIndex, depth, color`.
  Parents come before children.
- `slices.json` → `species`: `{id, name, plates, planeLabel, hemisphere?, maps,
  mapForLevel, decayMm}`. Mouse maps `["default"]`, decay 0.75 mm; human maps
  `["gyral","brodmann"]`, mapForLevel easy/medium → gyral, hard → brodmann, decay 5 mm.
  Variants are keyed by quality `sharp` / `light`; `labels` is `{map name: file}`.
- Human files: `plate_NNN_{sharp,light}.jpg`, `plate_NNN_{sharp,light}_{gyral,brodmann}.bin.gz`,
  `plate_NNN.regions.json` (`{map: {index: stats}}`); slices also have `section`, `atlasImageId`;
  `apMm` = (section − first section) × 50 µm.
- Mouse: `coronal_XXX_{25um,10um}.bin.gz`: label map for the slice at 25 µm AP index XXX
  (always even, so the 10 µm index 2.5·XXX is whole); **gzip** of raw **little-endian
  uint16**, row-major; value at (x, y) is `data[y * width + x]`; values are structure
  *indices*. x = left→right, y = dorsal→ventral. 25 µm 456×320, 10 µm 1140×800.
- `coronal_XXX_{25um,10um}.png`: 8-bit grayscale template, same size as its label map.
  One contrast window per resolution (0.5–99.5th percentile of brain pixels).
- `coronal_XXX.regions.json`: `{index: {areaPx, centroid: [x, y]}}` at 25 µm for every
  region on the slice, **aggregated up the tree**. Not used by the game yet.
- `slices.json` (~55 KB, loaded at start): `{source, levels, bestSlice, slices}`.
  `levels` = every region index of each difficulty (before the size filter);
  `bestSlice` = region index → slice id where it is largest (study search). Each slice:
  `id, plane, index, apMm, variants.{25um,10um}.{width,height,mmPerPixel,image,labels},
  regions, targets.{easy,medium,hard}` (indices that may be asked on that slice).

## Game rules
- Species picker first; URL `#mouse` / `#human`; top-bar switch. Each species has its own
  menu, best scores, review progress and study mode.
- Mouse: 36 coronal slices, evenly spaced over AP positions where brain area ≥ 25 % of max.
  Human: all 106 annotated plates (one hemisphere, midline on the left).
  The game loads a slice when its round starts and prefetches the next one.
- Quality setting (menu, saved): Sharp (default) / Light. Mouse 10 / 25 µm; human
  downsample 6 / 7. Same slices and questions; scoring uses that variant's label map.
- **Scoring distance scales with brain size**: `species.decayMm` = 0.75 mm mouse, 5 mm human
  (human hemisphere ~12× wider; 5 mm ≈ the same fraction of the image width).
- Human levels (`build_human.py`): easy = 6 lobes + thalamus, caudate, putamen, globus
  pallidus, hypothalamus, amygdala, hippocampus, claustrum, lateral ventricles, midbrain,
  pons, medulla, cerebellum (19); medium = gyri + cerebellar lobules + 37 classic nuclei/
  tracts (99, 95 askable); hard (Brodmann map) = Brodmann areas + main-group structures with
  layer-level names rolled up ("stratum pyramidale of rostral CA1" → CA1) (616, 508 askable).
  Minimum areas 20 / 12 (gyri) / 2 (nuclei, hard) mm² ≈ the mouse limits in screen pixels.
- Difficulty levels (`build_atlas.py`):
  - easy: Isocortex, OLF, HPF, CTXsp, STR, PAL, TH, HY, MB, P, MY, CB, fiber tracts, VS
  - medium: Allen set 3 "Mouse - Areas" (incl. functional groupings like DORsm/DORpm,
    MBsen/mot/sta, P-/MY-sen/mot/sat, PVZ/PVR/MEZ/LZ — owner chose to keep them) **plus**
    `MEDIUM_NUCLEI`: 62 classic exam nuclei (LGd, VPM, PVH, SCH, SNr, VTA, LC, IO, CA1…)
  - hard: Allen set 167587189 "Summary Structures", **excluding** "fiber tracts" (whole
    white matter as one entry) and names ending ", unassigned" (SSp-un)
  - asked on a slice only if area ≥ 0.5 / 0.3 / 0.05 mm² (easy / medium / hard);
    the medium nuclei use 0.05 mm² (PVH, SCH, LC never reach 0.3). Askable: easy 14,
    medium 109 of 113, hard 295 of 314.
- Rounds pick a **region first** (weighted by its review box, see below), then a random
  slice where it can be asked. A game asks each region once before any repeats, never
  the same twice in a row.
- Distance = click to nearest point of any pixel within the target (either hemisphere),
  measured to pixel edges (click inside → 0). Points = round(1000·exp(−d / 0.75 mm)).
- Partial credit: click inside the target's parent → at least 250, only if the parent
  is not root/grey (depth ≥ 2) **and** its area on that slice is ≤ 4× the target's
  (`MAX_PARENT_AREA_RATIO`). Chosen from data: keeps TH→IB (1.9×), CA→HIP (1.4×);
  drops cortical areas → Isocortex (20–37×).
- After a click, the result names the exact region clicked and, if different, the
  region of the current level containing it (`tree.ts:regionAtLevel`).
- 10 rounds. localStorage: `brain-atlas:best-score:<species>:<level>`,
  `brain-atlas:progress:<species>`, `brain-atlas:quality` (sharp|light),
  `brain-atlas:species`. Pre-M5 keys (`best-score:<level>`, `progress`, quality
  `10um`/`25um`) are still read for mouse (`storage.ts`, tested). Final screen shows a rank
  title (`game.ts:RANKS`).

## Review / spaced repetition (M4, `review.ts`)
- Every answered region gets a record in localStorage `brain-atlas:progress:<species>`
  (`{version: 1, gamesPlayed, regions: {<Allen id>: {box, tries, hits, lastGame, lastPoints}}}`),
  keyed by **Allen id** (stable across data rebuilds), shared by all levels.
- Leitner boxes 1–5: hit (≥ 750 pts) → box + 1; miss (< 400) → box 1; between → stays
  (first answer: miss → 1, otherwise → 2). Box ≥ 4 = "mastered".
- Due when `gamesPlayed − lastGame ≥ [0, 1, 2, 4, 8]` for boxes 1–5 — counted in games,
  not days. `gamesPlayed` increases when a game (normal or review) starts.
- Normal games weight regions by box: unseen 3, box 1 → 6, 2 → 4, 3 → 2, 4 → 1, 5 → 0.5.
- Review game: up to 10 due regions, most urgent first (lowest box, oldest, worst last
  answer), shuffled; each asked at the easiest level that includes it; no best score.
- Shown: due count on the Review card, "mastered X / Y" per level card, badges on the
  end screen (→ review / ↑ learning / ★ mastered), "Your record" line in study mode.
  "Reset review progress" on the menu clears records (best scores kept).

## Study mode
Slider/←→ over all 36 slices; detail level Divisions/Areas/Detailed = easy/medium/hard
sets; outlines (on) and Allen colours (off) at that level; hover (mouse) or tap names
the region at that level, with breadcrumb and which game levels ask it; search
(datalist of all level regions) jumps to `bestSlice` and selects the region.
Human: "Cortex map: Gyri | Brodmann areas" switch, kept consistent with the detail level
(gyri only exist in the gyral map, Brodmann areas only in the Brodmann map).
